Tôi là developer của app quản lý khách sạn (Laravel backend + React TypeScript frontend + Ant Design). Cần triển khai chức năng xuất hoá đơn PDF cho booking. Hãy CHỌN và TRIỂN KHAI ngay bằng barryvdh/laravel-dompdf (đã quyết định).

THÔNG TIN HỆ THỐNG:
- Backend: Laravel, có sẵn ReceptionController, routes/api.php
- Frontend: React + TypeScript + Ant Design, có BookingDetailModal.tsx
- Database: booking, booking_rooms, booking_services tables
- Endpoint hiện tại: GET /api/reception/bookings/{id} trả booking details

YÊU CÂU THỰC HIỆN:
1. Cài đặt: composer require barryvdh/laravel-dompdf và publish config
2. Tạo route: GET /api/reception/bookings/{bookingId}/invoice → trả PDF
3. Tạo controller method trong ReceptionController::generateInvoice()
4. Tạo Blade template: resources/views/invoice/booking.blade.php (layout đẹp, tiếng Việt, VND format)
5. Frontend: thêm nút "Xuất hoá đơn" trong BookingDetailModal, gọi API download blob

LAYOUT HOÁ ĐƠN (A4, đơn giản):
- Header: Logo + tên khách sạn + thông tin liên hệ
- Invoice Info: Số hoá đơn, ngày, khách hàng
- Table 1: Chi tiết phòng (tên gói, check-in/out, số đêm, giá/đêm, thành tiền)
- Table 2: Dịch vụ phát sinh (tên, số lượng, đơn giá, thành tiền)
- Footer: Tổng cộng, VAT (nếu có), ghi chú, chữ ký
