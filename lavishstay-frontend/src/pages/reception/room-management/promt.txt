Bạn là một developer backend Laravel; nhiệm vụ: tạo 2 template email đẹp responsive và controller + Mailables để gửi email cho ContactForm và Newsletter sử dụng cấu hình mail hiện tại (config/mail.php) và cấu trúc DB đã có (xem file SQL: có bảng coupons, coupon_redemptions, booking, payment). Chỉ cần tạo template + controller + mailable và route để frontend gọi — không thay đổi config mail hay thêm queue infra (dùng queue driver hiện có).

Yêu cầu chi tiết (làm đúng và ngắn gọn)

Đọc schema: dùng bảng coupons để lưu mã giảm giá 20% cho subscriber (không tạo bảng mới).

Bảng coupons có các cột chính: code, type (percent/fixed), value, start_at, end_at, usage_limit, per_user_limit, min_booking_amount_vnd, applicable_room_type_ids, active, created_by, timestamps.
Khi tạo mã cho newsletter: insert vào coupons với:
code = LAVISH20- + 6 chữ số ngẫu nhiên (uppercase)
type = 'percent', value = 20
start_at = now(), end_at = now() + 90 days
active = 1
điền description / created_by tùy ý
API endpoints (controller)

POST /api/contact

body { name, email, phone, subject, message }
Validate inputs.
Lưu record vào contact_messages (nếu chưa có, tạo migration nhỏ — optional; nếu không muốn migration, lưu vào log & reply).
Queue gửi 2 email:
To customer: ContactResponse Mailable (cảm ơn, tóm tắt, thời gian phản hồi).
To admin: quyenjpn@gmail.com notification with full details, Reply-To set to customer email.
Response: 200 { success:true, message: 'Đã nhận yêu cầu. Kiểm tra email để xác nhận.' }
POST /api/newsletter

body { email }
Validate, dedupe (nếu đã có trong newsletter_subscribers hoặc coupons assigned, return existing code).
Tạo coupon (see 1) và lưu.
Queue gửi 1 email: NewsletterWelcome Mailable includes big 20% code box, CTA button to booking page http://localhost:3000/booking?discount=CODE.
Add List-Unsubscribe header and unsubscribe link (route GET /api/newsletter/unsubscribe?email=...&token=...).
Response: 200 { success:true, discount_code: 'LAVISH20-XXXXXX' }.
Mailables & templates

Create app/Mail/ContactResponse.php and app/Mail/NewsletterWelcome.php extending Mailable and using ->queue() for sending.
Blade templates under resources/views/emails/:
contact-response.blade.php — header logo, greeting by name, summary of message, expected response time, support contact, footer.
newsletter-welcome.blade.php — hero illustration (use /resources/assets/illustration.svg or /images), big code box (visible on mobile), expiry info, CTA button, unsubscribe link.
Templates must be responsive, inline-styles acceptable; use color #1890ff as primary.
Coupon creation specifics (code sample pseudo)

$code = sprintf('LAVISH20-%06d', random_int(0,999999));
DB::table('coupons')->insert([... 'code' => strtoupper($code), 'type'=>'percent', 'value'=>20, 'start_at'=>now(), 'end_at'=>now()->addDays(90), 'description' => '20% cho newsletter', 'active'=>1, 'created_at'=>now(), 'updated_at'=>now() ... ]);
Unsubscribe & headers

Add List-Unsubscribe header in mailable: $message->getHeaders()->addTextHeader('List-Unsubscribe', '<' . $unsubscribeUrl . '>');
Unsubscribe route toggles a newsletter_subscribers row active=false (create table if missing) or stores token-based opt-out.
Use existing mail config

Use Laravel Mail facade; do not change config/mail.php. Use Mail::to($email)->queue(new NewsletterWelcome(...));
Queue & retry

Use default queue connection from .env (no infra steps). Jobs should be queued; wrap DB writes in try/catch and log errors. Set mailables to implement ShouldQueue.
Return values & frontend UX

For newsletter, return the generated code in JSON so frontend can display it immediately (and still send email). For contact, return success message.
Tests (minimal)

Add unit test to assert POST /api/newsletter creates coupon row and queues NewsletterWelcome mail.
Add unit test for POST /api/contact queues ContactResponse.
