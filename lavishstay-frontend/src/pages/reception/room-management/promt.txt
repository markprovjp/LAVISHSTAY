Giao diện phải đẹp, minimal, responsive, chỉ dùng Ant Design components chuẩn (Card, Descriptions, List, Row, Col, Tag, Statistic, Image, Space, Button, Divider, Typography, Tooltip, Collapse). Tránh tạo file CSS mới — dùng props AntD, spacing className tiện dụng và inline style tối thiểu (chỉ khi bắt buộc cho print). Giữ component self-contained và dễ test.
Dữ liệu (shape) — dùng để bind UI / test: { success: true, data: { booking: { booking_code: string, booking_id?: number, created_at: string, status: 'pending'|'confirmed'|'cancelled', payment_status: 'pending'|'completed'|'failed', guest_name: string, guest_email?: string, guest_phone?: string, check_in_date: string, check_out_date: string, total_price_vnd: number }, rooms: [{ room_name: string, selected_option_name?: string, selected_option_price?: number, adults?: number, children?: number, representative_name?: string, representative_phone?: string }], payment: { payment_method?: string, payment_url?: string, qr_code_url?: string }, summary: { total_rooms?: number, total_guests?: number, total_amount?: number } } }
UI/UX rules (concrete)
Header: AntD Result hoặc Space + CheckCircleOutlined + Title (message success). Dưới title hiển thị booking_code lớn (Typography.Title) có nút copy (Tooltip + Button with copy icon). Mã phải là visual anchor (màu chủ đạo AntD).
Layout: dùng Row/Col để tạo 2 cột trên desktop (left: Thông tin khách; right: Thông tin booking & thanh toán). Trên width nhỏ (xs), chuyển thành 1 cột.
Booking summary: dùng Descriptions (bordered, size="small") cho thông tin chung (check-in/out, nights, booking date, status as Tag).
Rooms: dùng List với Card type="inner" cho từng phòng; trái: optional Image (AntD Image) hoặc Avatar; phải: Descriptions nhỏ + giá (Statistic hoặc Typography.Text). Hiển thị subtotal = price × nights. Nếu có nhiều phòng, cho collapse/accordion khi >4 để rút gọn.
Payment summary: sử dụng Card hoặc Descriptions nhỏ ở bên phải/dưới, show final total lớn (Typography.Title/Statistic) màu khác (green). Nếu tồn tại qr_code_url show <Image src=... /> và thêm nút "Đã thanh toán" (verify).
Action bar: Space (horizontal) gồm: Copy code, Download Invoice, Print (window.print), Resend Email, View bookings, New booking. Đặt ở top và bottom; ẩn khi in (print). Buttons có aria-labels.
Accessibility: mọi button phải có aria-label; copy action nên focusable; trạng thái hiển thị text + Tag.
Print: minimal inline style for print (e.g., hide action buttons). Nếu bắt buộc, hướng dẫn dùng @media print inline style (tiny snippet).
Behavior / data fetching
Component nhận prop bookingCode string; fetch GET /api/payment/booking-details/{bookingCode} (fallback to /api/booking-details/{bookingCode} if needed).
10s timeout, spinner (Spin) while loading, show friendly Result with retry button on error.
Retry uses exponential backoff up to 3 attempts (document only).
For payment verification: if booking.payment_status === 'pending' and payment.payment_method === 'vietqr' then show "Đã thanh toán" button which calls POST /api/payment/verify-vietqr with { booking_code }, on success re-fetch and show success toast.
